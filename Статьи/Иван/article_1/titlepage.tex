\begin{abstract}
Разработка бортовых навигационных приемников для малых космических аппаратов (МКА) формата CubeSat требует применения алгоритмов параллельного поиска (PCPS) для преодоления высокой динамики доплеровского сдвига. Однако традиционное событийно-управляемое моделирование таких трактов сталкивается с вычислительным барьером при обработке длинных выборок сигнала. В данной работе предложена методология сквозной верификации тракта первичного поиска GPS L1, объединяющая синтезируемую RTL-модель на SystemVerilog и программное окружение на C++ в единый исполняемый файл с помощью компилятора Verilator. Использование статического планирования графа схемы и нативной интеграции C++ позволило реализовать адаптивный детектор Неймана–Пирсона с оценкой шума по выборке без накладных расходов на межъязыковое взаимодействие. Экспериментальные результаты на модели сигнала с отношением сигнал/шум –25 дБ подтвердили работоспособность комплекса: полное сканирование пространства «задержка–Доплер» в диапазоне ±50 кГц (201 частотный срез) выполнено за один прогон симуляции
\end{abstract}

\noindent \textbf{Ключевые слова:} GPS L1, первичный поиск, PCPS, критерий Неймана--Пирсона, Verilator, CubeSat, SystemVerilog, HW/SW Co-design, ASIC.
