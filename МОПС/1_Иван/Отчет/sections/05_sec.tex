\section{Выводы}
\begin{enumerate}
    \item Реализован оптимальный квадратурный некогерентный коррелятор для поиска сигнала ГЛОНАСС L1OF в двухмерной области неопределенности параметров $(\tau_{\text{з}}, f_{\text{д}})$ на выходе 3-уровневого АЦП.
    \item Рассчитан теоретический порог обнаружения по критерию Неймана--Пирсона при фиксированной вероятности ложной тревоги $P_{\text{ло}} = 10^{-4}$.
    \item Для выборки варианта 8 успешно обнаружен сигнал со следующими оценками параметров: доплеровский сдвиг частоты $\hat{f}_{\text{д}} = 1500\text{ Гц}$, задержка распространения $\hat{\tau}_{\text{з}} = 0.1556\text{ мс}$.
\end{enumerate}
