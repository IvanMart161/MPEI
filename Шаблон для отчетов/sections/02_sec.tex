\section{Теоретические сведения}
Для расчета эквивалентного сопротивления используется формула:
\begin{equation}
    R_{eq} = \frac{R_1 \cdot R_2}{R_1 + R_2}
\end{equation}

\subsection{Дополнительные сведения}
Данные соотношения справедливы для линейных электрических цепей.
