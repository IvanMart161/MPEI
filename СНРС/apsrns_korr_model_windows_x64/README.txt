АПСРНС — модель коррелятора (Windows x64)

Запуск:
1. Распакуйте весь архив в отдельную папку.
2. Запустите apsrns_korr_model.exe.

Важно: не переносите только EXE отдельно. Каталоги yp4, adc, platforms
и остальные DLL должны оставаться рядом с программой.

Сборка: Release, Qt 6.11.2, MinGW 64-bit.
